# Install in Gemini

## As a Gem (one paste)
1. Gemini → **Gems** → **New Gem**.
2. Name it "AWS Marketplace GTM."
3. Paste the **Operating instructions** from [`pack/gtm-skill-pack.md`](../pack/gtm-skill-pack.md) into the Gem instructions, then paste the ten skills under a "Skills" heading in the same field.
4. Save the Gem, select it, and ask for a skill: *"Build my pricing story."*

Tip: if the instructions field has a length limit, keep the Operating instructions + the two or three skills you use most; swap others in as needed.

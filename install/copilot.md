# Install in Microsoft Copilot

## As an agent / custom prompt (one paste)
1. Open Microsoft Copilot → start a new chat, or create an agent in **Copilot Studio**.
2. Paste the **Operating instructions** from [`pack/gtm-skill-pack.md`](../pack/gtm-skill-pack.md) as your first message (or as the agent's instructions).
3. Paste the eight skills so Copilot has them in context (or add the file as a knowledge source).
4. Invoke a skill by name: *"Run Agent-Ready Positioning on our product."*

## As live tools (Foundry) — coming
In Copilot Studio, connect the GTM **MCP server** so Copilot runs the skills as tools. Paid Foundry tier — see [`docs/MCP-SERVER-SCOPE.md`](../docs/MCP-SERVER-SCOPE.md).
